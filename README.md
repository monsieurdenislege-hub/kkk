# MOSANTU APP

Application mobile communautaire de l'Église Des Saints.

Ce dépôt contient un **starter Flutter** aligné sur le PRD v1.0 (mai 2026) avec :
- navigation 6 onglets ;
- structure modulaire par fonctionnalités ;
- base de modèles de domaine ;
- feuille de route technique MVP.

## Démarrage rapide

1. Installer Flutter (stable)
2. Lancer :
   ```bash
   flutter pub get
   flutter run
   ```

## Structure

- `docs/PRD_MOSANTU_APP.md` : PRD complet
- `lib/main.dart` : point d'entrée et navigation principale
- `lib/src/features/*` : écrans v1 par onglet
- `lib/src/core/*` : thème, constantes, utilitaires
